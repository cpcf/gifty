# Exchange workspace — Operate

## Direction contract

THESIS: A shared occasion with a private giving task. Make the next action obvious: invite, draw, then choose a gift.

OWN-WORLD: Aubergine navigation, acid-lime actions, pale lilac fields and white working surfaces. A rounded system sans with large, tightly spaced headings. Structured rows and spacious sections rather than nested cards.

STORY: Sign up, set the occasion, send an invitation link, check the guest list, draw once. Personal wish lists sit alongside exchanges.

FIRST VIEWPORT: Slim brand navigation; a large left-aligned heading and a single primary action; exchange rows show date, budget and state. The empty state uses an oversized typographic gift label and clear first action.

FORM: Code-led product UI. Impeccable's upstream guidance was read; its launcher is not installed. User-directed unattended decision-making overrides the interactive concept-selection workflow.

FINISH: Review rendered desktop/mobile layouts and real multi-user behavior, document the implemented design, and fix observed defects. No raster assets are needed.
